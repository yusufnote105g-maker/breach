# Breach

Офлайн 3D-арена: шутер от первого лица на Godot 4.7, собранный и проверенный в CI.
Без сети, без рекламы, без ассетов из чужих игр — вся геометрия строится кодом.

## Что внутри

| Механика | Реализация |
|---|---|
| Уровень | арена 64×64, стены, ящики, укрытия — генерируется кодом (`scripts/game.gd`) |
| Движение | `CharacterBody3D`, гравитация, прыжок, ускорение по земле |
| Обзор | yaw/pitch, чувствительность, ограничение по вертикали |
| Стрельба | хитскан-луч из камеры, `PhysicsRayQueryParameters3D`, урон 34 |
| Враги | 4 бота: преследуют, наносят урон по дистанции, умирают с 3 попаданий |
| HUD | HP, патроны, фраги, число врагов, FPS, прицел, кнопка огня |
| Мобильный ввод | левая половина экрана — стик движения, правая — обзор, кнопка «ОГОНЬ» |
| Смерть | экран «ВЫ УБИТЫ», респавн через 2 с |
| Перезарядка | автоматическая при пустом магазине (1.4 с) |
| PC | WASD + мышь + ЛКМ, Esc отпускает курсор |

## Сборка

CI (`.github/workflows/ci.yml`):

1. скачивает Godot 4.7.2 headless и export templates (кэшируются);
2. импортирует проект и прогоняет **headless boot test** (`--quit-after 30`) — если
   скрипт не компилируется или сцена падает, сборка красная;
3. генерирует debug-keystore;
4. экспортирует `build/breach.apk` (`--export-debug Android`);
5. проверяет APK как zip (`AndroidManifest.xml`, `classes.dex`, `lib/`);
6. публикует релиз `build-N`.

Локально: `godot --path . --export-debug "Android" build/breach.apk`.

## Ограничения

- Это прототип, а не Free Fire: нет неткода, анимаций, звука, скинов, античита.
- Модели — капсулы и кубы; полигонов почти нет, поэтому 60 FPS достижимы.
- Боты ходят напрямую к игроку, без навигационной сетки и укрытий.
